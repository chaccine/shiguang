# Unit-0.11 · M04 展馆设计与交互

延续 Unit-0.10 的 A 暖纸本与独立「灯下展馆」。只新增展馆组件，不改变正式内容、照片色彩或系统主题偏好。

- 首页四区按 01–04 编号；名称、实际数量、规则说明、真实预览和入口构成展签。
  文字记录有独立衬纸卡，不补默认图。桌面两列展柜，手机单列；并列展柜入口在底端对齐。
- 今日重逢采用年份分节；珍藏采用横向展签，手机回到纵排；照片墙桌面四列、手机两列；
  年室以大年份和 12 月份分布展开。入口共用字形和展框，内部浏览节奏各有区别。
- 日间：浅纸墙、纸白衬垫、陶木边线、暖色展签和轻阴影。夜间：胡桃木墙、暖墨衬垫、
  黄铜展签与静态顶部微光。材质均为 CSS，使用本机字体；照片无滤镜、透明度或叠色。

## 新语义 token

两主题在 `src/ui/tokens.css` 独立定义：
`museum-wall`、`museum-mat`、`museum-placard`、`museum-label`、`museum-frame`、
`museum-track`、`museum-bar`、`museum-light`、`museum-shadow`。

新组件 `museum.css` 只引用 token；展签继续消费通用 primary/secondary/muted 文字。
自动计算检查三种新背景及聚光叠加上文字 ≥4.5:1、焦点 ≥3:1，月份条与底槽 ≥3:1。
边框是辅助装饰，不承担唯一状态表达。月份有可见数值、月份文字及完整 aria-label。
触控目标继承全局最小 44px / 常用 48px；照片有固定比例衬框和 lazy 属性。

## 行为

- 所有卡片按 recordId 进入既有正式阅读页；编辑仍走既有 M01。
  阅读返回重新查询当前投影，恢复展区、排序、加载数量、主滚动区/window 偏移及可用的原焦点。
- 展区内部的返回也保存这些上下文。常规列表/照片每次增量 24 项；年份列表每次 24 间。
  IntersectionObserver 触发续页，同时保留「继续看更多」按钮。查询失败保留现有内容，手动重试。
- 照片按 photoUseId 展示，caption 纯文本；无说明的替代文本使用「照片 n，来自《title》/无标题记录」。
  展墙使用单一 Tab 停靠点，方向键/首尾键移动；查看器为原生 modal dialog，左右键/按钮换图，
  Escape 关闭，返回打开它的照片。原生模态提供 Tab 焦点约束；锁屏 inert 时不重开查看器。
- 隐藏仅在今日重逢、偶遇推荐、年度精选处出现；保留原记录、珍藏展柜和照片墙。
  成功后提供撤销；「我的 → 隐私 · 回忆推荐偏好」复用 Task A 的全部重置命令。
  durability=uncertain 时明确未获系统落盘确认。再看一段优先未看过的合格记录。
- 减少动态效果继承全局规则，并取消预览照片的装饰旋转。不新增动画或外部资源。

## 证据边界

Node 事件 DOM 夹具实际调用 MuseumUi/MemoryAdapter，验证导航、分页、按键处理、焦点目标、
上下文恢复和错误路径；不模拟浏览器布局、真实焦点派发、模态 Tab 或图片解码。
5000 条首页预算为 1000ms，首屏最多 5 张故事卡 / 8 次缩略请求；不是设备帧率承诺。
浏览器、读屏、200% 字号和平台实际触控仍需编排侧/设备验证。

`screenshots-u11.mjs` 的长页采集临时展开 `.main`，手机导航锚定采集末端，避免全页图中间穿条。
查看器与 `nav-single-plus` 使用真实视口，不应用该采集样式；此样式不进入产品 CSS。
