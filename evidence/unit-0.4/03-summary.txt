浏览器预览入口（由 MemoryAdapter 自动读取 window.location.search）
- ?fail=locked：storeStatus() 返回 STORE_LOCKED；其他 API 均拒绝该错误，存储不读写。
- ?fail=schema：同上，错误为 SCHEMA_TOO_NEW。
- ?media=missing 或 ?missing=1：模拟被引用原图缺失；?media=corrupt 模拟校验失败。
- 可用 setPhotoStatus(assetId, "missing" | "corrupt" | "available") 单独模拟；也可通过构造参数 missingAssets/corruptAssets 注入。
- mediaReport() 返回 missing/corrupt；photoStatus() 返回对应状态；photoDataUrl() 拒绝 ASSET_MISSING / ASSET_HASH_MISMATCH。模拟不改写记录或原图。
- 构造参数 search 可在 Node 中注入相同 URL 参数。此任务未修改 src/ui/，具体提示界面由 UI 阶段接入。
