回收站

回收站不会自动清空，只有你手动操作才会永久删除。

数据与备份

备份是一份可以带走的完整副本，不是云同步。

本机数据会随卸载或清除应用数据一起消失。请定期导出备份，并把备份文件存到这台设备以外的地方（电脑、U 盘、网盘等）。

导出备份

把正式记录、草稿、回收站、冲突副本、删除记录和照片原件打包成一个 .sgbak 文件。导出不会改动现有数据。

这是未加密的明文备份，任何拿到文件的人都能读到内容，请妥善保管。

从备份恢复

先选择备份文件，拾光会完整校验（文件是否完整、是否被修改、版本是否兼容），校验通过后才会让你决定是否恢复。

覆盖恢复会用这份备份替换当前全部数据；恢复前会自动在本机留一份当前数据的安全副本。

还没做的功能

  • 未实现安全合并：把备份合并进现有数据（目前只有整库覆盖恢复）。
  • 未实现口令加密备份：目前导出的都是明文备份。
  • 未实现防复活检查：合并旧备份时阻止已永久删除的内容回来（依赖安全合并）。

删除记录（墓碑）已经随备份一起保存，为以后的合并与防复活做准备。
